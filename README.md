# Week 12 – Advanced Social Media Platform
A learning starter for real-time chat/notifications, media upload integration, API testing, security basics, Docker, CI, portfolio and resume preparation.

## Run locally
1. Install Node.js 20+.
2. In `backend`: copy `.env.example` to `.env`, run `npm install`, then `npm run dev`.
3. In `frontend`: run `npm install` and `npm run dev`.
4. Open two browser tabs to test chat.
5. Run tests with `cd backend && npm test`.

This is a starter/demo, not a production-ready social network. It has no database persistence, complete authentication, moderation, full social feed, or verified live deployment. Socket room authorization must be added before real use.
